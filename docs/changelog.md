# Daedalus Changelog

> A history of how this Linux environment has evolved.

# 2026-07-28

## Created Daedalus Dotfiles Repository

Created a Git repository to store and manage my Linux environment.

Purpose:

- prevent losing customisations
- make future rebuilds easier
- prepare for moving to future machines such as Achilles

The repository now stores:

- scripts
- configurations
- package lists
- documentation

---

# 2026-07-28

## Created Weather System

Built a custom location-based weather system.

Features:

- `weather-location` command
- weather status display
- weather icons
- Waybar integration
- saved location configuration

The goal was to make changing locations simple.

Example:

```bash
weather-location Hyderabad
```

This allows my laptop to adapt when travelling.

---

# 2026-07-28

## Added Timezone Integration Idea

Expanded the weather system concept so that changing location can eventually update:

- weather location
- system timezone
- clock display

The idea is that my computer should understand where I am.

# 2026-07-28

## Added Battery Monitoring

Created a battery warning system.

Features:

- automatic battery checking
- low battery notifications
- systemd timer integration
- Omarchy notification support

This fixed the lack of a battery reminder in the default setup.
